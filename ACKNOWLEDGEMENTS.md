# Acknowledgements

The original team project was created by **Yunhe Zhang, Yunshen Song, Evelyn Feng, and Xiyu Yang** for Cornell CS 4782/5782.

The implementation builds on **DoRA: Weight-Decomposed Low-Rank Adaptation** by Liu et al. (2024). DoRA is the underlying published method; DoRA Forge is the showcase name for this team's implementation and application work.

The project uses the PyTorch and Hugging Face ecosystems, LLaMA-family checkpoints, Stable Diffusion XL, Anthropic HH-RLHF, and commonsense reasoning benchmarks. Image references and data sources include the [Chinese Landscape Painting Dataset](https://github.com/alicex2020/Chinese-Landscape-Painting-Dataset) and TU-Berlin sketch data.

The repository retains the original project's license. Pretrained models, datasets, third-party content, and their trademarks remain subject to their respective terms. Raw training datasets and model weights are not included in this showcase package.

Generated outputs are labeled by their source method. No newly generated or retouched image has been substituted for an experiment output.
